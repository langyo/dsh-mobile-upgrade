# dsh-mobile-upgrade

[English](../../README.md) | [简体中文](../zh-Hans/README.md) | [繁體中文](../zh-Hant/README.md) | [日本語](../ja/README.md) | [한국어](../ko/README.md) | [Español](../es/README.md) | [Français](../fr/README.md) | [Deutsch](../de/README.md) | Русский

Удобства для мобильных устройств в веб-профиле [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`), оформленные как один плагин. Всё отрисовывается через собственные слоты и сигналы состояния хоста — без захвата разметки, без плавающих виджетов, без опроса DOM чата.

## Что вы получаете

- **Загрузка вложений в композере** — кнопка-скрепка рядом с рядом инструментов композера. Изображения идут через нативный путь вставки вложений редактора; любой другой файл загружается на сервер, и его абсолютный путь вставляется в черновик, чтобы агент мог прочитать файл своими инструментами.
- **Строка перезапуска** — пункт «Перезапустить службу» в Настройки → Общие. Сначала запрашивает подтверждение, перезапускает процесс `dsh` и автоматически перезагружает страницу, когда служба снова отвечает.
- **Переключатели модальностей ввода** — флажки text/image/video в каждой строке модели нативного редактора провайдеров, записывающие массив `input` модели в `settings.yaml` (с резервной копией рядом с файлом). Для моделей каталога без пользовательской маршрутизации переключатели показываются только для чтения.
- **Боковая панель-шторка на узких экранах** — ниже 1024px боковая панель сворачивается в маленький угловой чип, сохраняющий собственный переключатель хоста; в развёрнутом виде вся панель всплывает шторкой поверх контента во всю ширину, а выбор сессии снова её закрывает.
- **Вкладки настроек на узких экранах** — ниже 700px боковая навигация диалога настроек превращается в ряд горизонтально прокручиваемых вкладок.
- **Меню моделей во всю ширину** — ниже 700px меню моделей композера привязывается ровно к ширине экрана (поля 12px) вместо выхода за край экрана; вертикальное размещение над триггером остаётся за хостом.
- **Обход панели деталей** — полноэкранная панель деталей инструментов, кнопка закрытия которой в текущем хосте не работает, на узких экранах не отрисовывается вовсе, поэтому не может заблокировать чат.
- **Переключатели по функциям** — плагин устанавливает раздел `mobile-ui-fix` в Настройки → Плагины с переключателем для каждой функции.

## Установка

```sh
dsh plugin --profile web add dsh-mobile-upgrade
```

Перезапустите `dsh web` и откройте веб-профиль на телефоне: скрепка появится в композере, строка перезапуска — в Настройки → Общие, а переключатели — в Настройки → Плагины → mobile-ui-fix.

Требуется `dsh` 0.1.2-rc.1 или новее.

## Конфигурация

Карточка настроек плагина принимает:

| Ключ | По умолчанию | Значение |
|---|---|---|
| `uploadDir` | `<dsh home>/mobile-uploads` | Где хранятся загрузки, кроме изображений |
| `restartEnabled` | `true` | Предоставлять строку перезапуска и её маршрут |

## Переключатели функций

Каждую функцию можно включать и выключать в Настройки → Плагины → mobile-ui-fix (вступает в силу при следующей загрузке страницы) либо переопределить на устройстве ключом `localStorage` — `mfx-attach`, `mfx-restart`, `mfx-settle`, `mfx-drawer`, `mfx-settings`, `mfx-modality`, `mfx-menus` — значение `"0"` отключает функцию.

## Известные ограничения

- Клиент цепляется за конкретные элементы интерфейса хоста по их хешированным CSS-классам (меню, переключатель шторки, редактор провайдеров). Если сборка хоста переименует их, затронутые функции деградируют, пока этот плагин не догонит; остальное продолжает работать.
- Переключатели модальностей ввода могут изменять только маршруты провайдеров, настроенные вами самостоятельно; маршруты из одного каталога только для чтения по замыслу — выдуманный раздел каталога обрушивает весь каталог моделей.

## Замечания по безопасности

HTTP-маршруты плагина (загрузка, перезапуск, правка настроек) сами по себе не выполняют аутентификацию — они доверяют веб-поверхности `dsh`, в которую загружены. Прежде чем открывать развёртывание за пределы localhost, поместите его за ту же преграду, что и остальной интерфейс (аутентификация обратного прокси, привязка к loopback).
